# Release policy

This repository is a private review package. Do not publish, tag a public release, or expose it through a marketplace without a separate approval.

Before any public release:

1. Review all examples and adapters for personal defaults and machine-local assumptions.
2. Decide the public license, author attribution, repository name, and support channel.
3. Test installation from a clean environment for every supported agent format.
4. Re-run the portability validator and review the full diff.
